## Easy
1. 1D Array (Fibonacci Style) - just DP[n] = DP[n-1] + DP[n-2]

2. 1D Array (Kadane's Algorithm) - max subarray sum, simple

## Easy-Medium
3. 2D Array (Unique Paths on Grid) - DP[i][j] = DP[i-1][j] + DP[i][j-1]

4. 1D Array (Word Break Style) - DP[i] = can segment up to i

## Medium
5. 1D Array (0/1 Knapsack Subset Sum Style) - choose or not choose

6. 1D Array (Coin Change / Unbounded Knapsack) - unlimited items

7. Longest Increasing Subsequence (LIS) - O(n²) DP, then binary search O(n log n)

## Medium-Hard
8. 2D Array (Longest Common Subsequence - LCS) - 2D matching

9. Partition DP - split array into k parts (e.g., Palindrome Partitioning)

## Hard
10. 2D Array (Edit Distance) - insert, delete, replace operations

11. Interval DP - DP on intervals (e.g., Burst Balloons, Stone Game)

12. Catalan Numbers - combinatorial DP (e.g., Unique BST, Parentheses)
