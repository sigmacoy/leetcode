INNER JOIN: Keeps only rows where there is a match in both tables.
INNER JOIN == JOIN

LEFT JOIN: Keeps all rows from the left table 
+ matching rows from the right (fills with NULL if no match).

    Table: SalesPerson (s)
    | sales_id  | name      |
    | :---      | :---      |
    | 1         | Alice     |
    | 2         | Bob       |

    Table: Orders (o)
    | order_id  | sales_id  | amount |
    | :---      | :---      | :--- |
    | 101       | 1         | 500 |

    Result:
    s.name      s.sales_id      o.order_id      o.amount
    Alice       1               101             500
    Bob         2               NULL            NULL

RIGHT JOIN: Keeps all rows from the right table 
+ matching rows from the left (fills with NULL if no match).

Inner is the intersection; 
Left/Right preserves one side entirely.
