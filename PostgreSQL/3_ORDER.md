# the Order of Execution

1. FROM - find source

2. JOIN - Combine Data

3. WHERE - Filters the individual rows

4. GROUP BY - Groups rows into buckets

5. HAVING - Filters the groups

6. SELECT - select columns

7. DISTINCT - Removes duplicate rows

8. ORDER BY - Sorts the final list

9. OFFSET - SQL skips the rows

10. LIMIT - takes the remaining number of rows requested.
